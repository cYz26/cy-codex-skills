# Review Checklist

- [ ] Target State describes the complete requested outcome.
- [ ] Completion Contract is concrete and evidence-based.
- [ ] Capability Slices are dependency-ordered and independently verifiable.
- [ ] No required capability is deferred to future work.
- [ ] Execution Ledger has clear statuses and validation evidence.
- [ ] Validation Commands are runnable or have documented blockers.
- [ ] Goal Mode Prompt and Continue Prompt point to the ledger.
- [ ] Final Verification covers tests, lint/typecheck/build where relevant, and manual checks when needed.
