# Context Fixer Naming Notes

## Name

The product name is **Context Fixer**.

The Chinese working idea is 「清道夫」. It describes the role this tool plays
behind polished AI workflows: when a large-model session looks smooth on the
surface, there is still dirty work underneath. Context grows, tool output gets
messy, traces contain sensitive details, instructions drift, and compaction
decisions become hard to time.

Context Fixer is the professional operator for that hidden work. It audits,
attributes, cleans up, and recommends the next move so the high-level Codex
experience can stay sharp.

## Tone

- Professional, calm, and practical.
- Handles messy context without exposing sensitive bodies.
- Works locally and read-only by default.
- Treats request traces as opt-in evidence, not as something captured silently.

## Inspiration Boundary

The name idea nods to the "fixer" archetype and to the user's affection for the
TV drama known in Chinese as 「清道夫」. The tool should not use protected character
names, likenesses, posters, or franchise-specific visual marks. Visual design
should stay original: a pixel-art professional fixer, context debris, terminal
grids, cleanup tools, and a crisp recovered surface.
